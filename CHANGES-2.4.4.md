# Версія 2.4.4

- Групи мають власні кольори: палітра та довільний колір у редакторі групи. Робота в табелі забарвлена за групою призначення, нижче показана легенда. Відсутності зберігають свої позначення.
- Активні особові картки можна архівувати. Остаточне видалення доступне лише адміністратору після архівування й точного введення ПІБ.
- Сервери Python та Cloudflare блокують видалення карток через звичайне збереження. Перед дозволеним видаленням автоматично створюється резервна копія; дія потрапляє до журналу.
- Відновлення JSON виконується окремою дією адміністратора.
