# Версія 2.5.0

- Тимчасова заміна на вибрані дати включно: основна людина залишається до заміни й автоматично повертається після неї. Інші учасники, ВП та посада на зміні зберігаються. Доступно адміністратору з вікна зміни або клітинки людини.
- Індивідуальне призначення обов’язково містить точку / ВП. Клітинка однієї людини вибирає тільки її, без автоматичного додавання всього екіпажу. Старі кадрові записи роботи при редагуванні перетворюються на призначення з ВП.
- Спрощено форму виходу: ВП, група, дати та учасники; додаткові поля розгортаються окремо. До збереження показані учасники та конфлікти.
- Сервери Python і Cloudflare відхиляють нові перетини роботи з відпусткою/лікуванням. Старі вже наявні конфлікти не блокують не пов’язані зміни; при спробі створити новий показані людина, тип відсутності й точка. Перетини двох робочих змін також перевіряються.
- На огляді додано вікно робочих змін: «Сьогодні», «Завтра», «Усі зміни», хто куди заступає та редагування звідти. Колонки відсутностей вирівняно.
- З графіка роботи прибрано верхнє зведення людей. Додано великий графік із прихованим меню та виходом у звичайний режим.
- Копіювання вибраних призначень або графіка на нову дату, тиждень чи місяць. Копії заплановані; тривалість і час за Києвом зберігаються; конфлікти перевіряються.
- «Скасувати останню дію» для адміністратора: відновлює останній кадровий стан з перевіркою версії та резервом поточного стану. Не змінює облікові записи.
- Історія клітинки показує автора, час та дію. Журнал можна догружати сторінками по 100 записів, включно після очищення клітинки.
