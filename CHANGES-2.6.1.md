# 2.6.1

- «Як користуватися» доступна в кожному розділі. Навчання містить 29 тем із нумерованими кроками, пошуком і відбором тем поточного розділу: люди, робота, заміни, перекат, відпустки, КЗВ, фільтри, експорт, доступи, резерви та адміністративні функції.
- У фільтрах графіків можна позначати кілька груп, людей, складів, посад і типів подій. Вибір застосовується кнопкою «Застосувати»; порожній вибір означає всі значення. Різні фільтри діють разом. На телефоні список відкривається великою панеллю.
- «Відпустки та КЗВ» замінили «Відпустки й лікування». Верхнє зведення в цьому розділі прибрано. Лікарняні, ВЛК і реабілітація приховані в календарі й формах нового оформлення; історія залишається в базі. Очищення календаря не прибирає приховані медичні записи чи роботу. Excel цього розділу містить лише відпустку та КЗВ.
- Вужчий закріплений стовпець людей, рівні заголовки днів, компактніший календар відпусток на телефоні. У відпустках доступні «Сьогодні» й «Великий графік».
- У робочих картках огляду та переліку змін показуються позивні без посад; для старих записів позивний береться з особової картки. Якщо позивного немає, залишається ім’я.
- Перейменування групи змінює ту саму групу, належність людей, активні та історичні призначення й колір без створення другого рядка. Посилання на конкретну групу продовжують працювати після перейменування. Редактору дозволено саме перейменування історичної групи без супутнього переписування історії.
- GitHub застосовує D1-міграції, коли у push змінені файли міграцій або вони явно запитані при ручному запуску. Звичайне оновлення інтерфейсу не потребує D1 Edit. Для нових міграцій право D1 Edit усе ще потрібне. Нових міграцій у цій версії немає.

Перевірки: серверні тести Python і Worker, тести фільтрів, перейменування, захисту історії, очищення й експорту; браузерні сценарії на комп’ютері та телефоні, включно з навчанням і відкликанням публічного посилання.
